# ♔ DiagPDF Web

Веб-приложение для генерации профессиональных PDF-сборников шахматных диаграмм и задач прямо в браузере. Без сервера, без регистрации и абсолютно бесплатно.

🔗 **Live Demo:** [https://aslyamov.github.io/diag_PDF/](https://aslyamov.github.io/diag_PDF/)

---

## ✨ Возможности

- ♟️ **Шахматные диаграммы высочайшего качества**: Поддержка шрифтов *Chess Alpha DG*, *Leipzig DG*, *Condal DG*, *Kingdom DG*.
- ⚡ **100% Client-Side**: Вся генерация происходит прямо в браузере с помощью `jsPDF` без отправки данных на сервер.
- 👁️ **Мгновенный предпросмотр**: Интерактивный просмотр готовых страниц PDF через `pdf.js` с точностью до пикселя.
- 📁 **Поддержка всех шахматных форматов**:
  - `.pgn` (партии и задачечники)
  - `.fen` (файлы с FEN-строками)
  - `.epd` (эндшпильные и тактические базы)
- 📖 **Настраиваемая структура документа**:
  - **Обложка** (автозаполнение заголовка, подзаголовка, автора и текущей даты)
  - **Оглавление** (автоматический расчет страниц для глав, диаграмм и ответов с кликабельными ссылками)
  - **Главы** (удобное разбиение задачечника на главы с каскадным автозаполнением диапазонов задач)
  - **Раздел ответов** (вертикальные колонки от 1 до 4 с поддержкой фигуринных шрифтов *Zurich*, *Hastings*, *Linares*)
- ✍️ **Строки нотации для записи решений**: Двухколоночные линии под диаграммами для записи ходов белых и черных (с нумерацией и регулируемым интервалом).
- 🔗 **Интеграция с Lichess**: Интерактивные кликабельные ссылки на значке хода для быстрого перехода к анализу позиции в Lichess.
- 🎨 **Удобный и продуманный UI**:
  - 🌓 Тёмная и светлая темы оформления.
  - 🌐 Полная двуязычность: **Русский** / **English**.
  - 💾 Автоматическое сохранение всех настроек в `localStorage`.
  - 📂 Компактные сворачиваемые секции (Accordion).

## 🛠️ Технологический стек

- **Core**: JavaScript (ES Next), HTML5
- **Styling**: Tailwind CSS v4, Vanilla CSS
- **PDF Engine**: `jsPDF`
- **PDF Renderer**: `pdf.js` (`pdfjs-dist`)
- **Build Tool**: Vite

## 🚀 Быстрый запуск локально

### Требования
- Node.js (версия 18 или выше)
- npm или yarn

### Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/aslyamov/diag_PDF.git
   cd diag_PDF
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

4. Откройте в браузере: `http://localhost:5173/`

### Сборка для продакшена

```bash
npm run build
```
Готовая сборка будет находиться в директории `dist/`.

## 🔄 Автоматизация и CI/CD (GitHub Actions)

В проект встроена полная автоматизация:

1. **GitHub Pages Deploy (`.github/workflows/deploy.yml`)**:
   При каждом пуше в главную ветку `main` запускается автоматическая сборка и публикация обновленной версии на GitHub Pages.
2. **Dependabot (`.github/dependabot.yml`)**:
   Еженедельно сканирует версии зависимостей (`jsPDF`, `Vite` и др.) и автоматически создаёт **Pull Request** при выходе обновлений. Вы можете легко одобрить обновление в 1 клик.
