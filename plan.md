# DiagPDF Web — Идеи для развития проекта (Roadmap & Ideas)

---

## 1. 🎨 Улучшения визуализации диаграмм (Diagram Visuals)

- [ ] **Кастомная цветовая палитра доски**
  - Поддержка темных полей с легким фоновым оттенком (вместо стандартной сетки шрифта).
  - Смена цвета индикаторов хода (белый/черный круг, квадрат, треугольник).
- [ ] **Графические стрелки и подсвеченные поля (PGN Annotations)**
  - Парсинг и отрисовка PGN-тегов `[%csl Gb3,Rd4]` (цветные поля) и `[%cal Ge2e4,Rf1f7]` (стрелки ходов).
- [ ] **Печать оценочных символов (NAG Annotations)**
  - Поддержка символов `$1` (!), `$2` (?), `$3` (!!), `$4` (??), `$14` (+=), `$15` (±) в тексте ответов и под доской.

---

## 2. 📖 Интерактивный редактор обложки и верстки

- [ ] **Шаблоны обложек (Cover Templates)**
  - Несколько стильных визуальных макетов: "Минимализм", "Классический шахматный учебник", "Журнальный".
  - Возможность загрузить собственное лого / фоновое изображение для обложки.
- [ ] **Иерархическая структура: Главы и Подглавы (Chapters & Subchapters)**
  - Поддержка вложенности позиций (например, `Глава 1. Дебютные катастрофы` $\rightarrow$ `Подглава 1.1. Ловушки в Сицилианской защите`).
  - Отображение иерархии в Оглавлении (TOC) с отступами и в заголовках страниц (Header).
- [ ] **Кастомные страницы-разделители глав (Chapter Divider Pages)**
  - Опция автоматической вставки полностраничной титульной страницы перед новой главой/подглавой.
  - Полноэкранный стильный макет: Название главы, диапазон задач, эпиграф/описание темы.
- [ ] **Нумерация диаграмм по главам и подглавам**
  - Опция выбора нумерации: Сквозная (1, 2, 3...) или иерархическая (`1.1`, `1.2`..., `2.1.1`...).

---

## 3. 🧩 Интерактивность и удобство работы (UX/DX)

- [ ] **Встроенный редактор FEN/PGN досок**
  - Возможность поправить позицию или ход прямо на веб-странице до генерации PDF.
- [ ] **Фильтрация и дубликаты**
  - Автоматическое выявление одинаковых позиций при импорте больших PGN-баз.
  - Фильтр по типу задач (например, показывать только задачи "Мат в 2 хода" или позиции с определенным соотношением материала).
- [ ] **Сохранение пресетов настроек (Presets Manager)**
  - Сохранение пользовательских профилей настроек (например: "Печать для детей", "Формат брошюры A5", "Книга с ответами") в `localStorage`.

---

## 4. 📤 Экспорт и интерактивные форматы

- [ ] **Экспорт диаграмм в PNG / SVG / SVG-Zip**
  - Возможность выгрузить все доски или выбранную страницу как пакет изображений высокого разрешения для использования в Word / ВКонтакте / Telegram.
- [ ] **Интерактивный штрихкод / QR-код для решебников**
  - Генерация QR-кода на странице с ответами со ссылкой на интерактивный разбор позиции на Lichess / Chess.com.
- [ ] **Печать в формате "Книжка-брошюра" (Booklet Layout)**
  - Автоматический спуск полос (Imposition) для последующего сшивания A4-листов в тетрадь A5.

## 5. ♟️ Поддержка дополнительных шахматных шрифтов

- [ ] **Шрифт Chess Merida (Unicode)**
  - Внедрение двухслойного вектора для поддержки легендарного гарнитурного шрифта Merida.
- [ ] **Шрифты Chess Cases / USCF**
  - Поддержка стандартизированных шрифтов Федераций для специализированной печати бланочной продукции.
